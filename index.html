Selected work

Five open-source projects

Personal reference implementations, not employer code. The first three run together as one system: a ledger, the service that delivers its events to external partners, and the console that operates both. Each repository's README opens with the problem and spends most of its length on the design decisions and their trade-offs.

  • ledger-core

    Service

    A double-entry accounting ledger: accounts, deposits, withdrawals, transfers and reversals over an append-only journal.

    • Money in minor units with per-currency scale — never a floating-point amount.
    • Idempotent writes: a repeated Idempotency-Key replays the stored response instead of posting twice.
    • Corrections are mirrored reversal entries, never mutations — the journal stays auditable.
    • Hexagonal layering, with domain logic that imports nothing from Spring.
    Java 21Spring Boot 3PostgreSQLFlyway
    Repository ↗

  • payments-integration-hub

    Service

    The delivery layer between a core banking system and external partners, built around the assumption that partners fail.

    • Transactional outbox: events are committed with the data that produced them, then dispatched.
    • At-least-once delivery with exponential backoff and jitter, and idempotent consumers on the other side.
    • A circuit breaker per partner, so one slow endpoint cannot drain the worker pool.
    • A dead-letter queue with manual replay and discard, instead of retrying forever.
    NestJSTypeScriptTypeORMPostgreSQL
    Repository ↗

  • ledger-console

    Interface

    The operator console for both services — the screens a back-office team would actually use to move money and unblock deliveries.

    • Standalone components, signals and zoneless change detection; no NgModules anywhere.
    • An interceptor chain owns correlation IDs, idempotency keys and retry-with-backoff, so no feature has to remember them.
    • The idempotency key is minted per user action, not per HTTP attempt — which is the whole point of it.
    • A mock backend ships in the repository, so npm start gives a working app with nothing else running.
    Angular 21TypeScriptMaterialRxJS
    Repository ↗

  • rag-policy-assistant

    Service

    A retrieval service that answers questions over a policy corpus and refuses to answer anything it cannot cite.

    • Hybrid retrieval — BM25 and vector search fused with Reciprocal Rank Fusion — because either half alone loses cases the other catches.
    • Citations are parsed and verified against what was actually retrieved, not trusted because the model produced them.
    • The language model sits behind a port, so the interesting engineering is testable without an API key.
    • An evaluation harness runs in CI: a drop in retrieval recall fails the build like any other regression.
    PythonFastAPIPydantic v2NumPy
    Repository ↗

  • fabric-migration-toolkit

    Tooling

    A command-line toolkit for moving Power BI workloads onto Microsoft Fabric, written after doing the same migration by hand.

    • A real lexer, parser and AST for Power Query M — regex substitution silently produces wrong transformations.
    • Translation emits PySpark source rather than executing Spark, so a human reviews the diff before anything runs.
    • TMDL models are parsed and re-serialised, so renaming a column cascades through every measure and relationship.
    • Unsupported constructs fail loudly and name themselves instead of passing through quietly.
    PythonPower Query MTMDLPySpark

About

I came to software from industrial automation. My first two and a half years were spent on instrumentation and control systems for oil and gas, where a defect is not a stack trace — it is a valve in the wrong position. That is where I learned to care about verification before deployment, and it is still how I think about backend work.

Since 2022 I have worked in banking: first at Grupo Bolívar, then at Banco Davivienda, one of Colombia's largest financial institutions, where I moved from building services to designing the architecture around them. Banking gave me the other half of the discipline — idempotency, auditability, integration contracts that survive contact with a partner's production environment.

I am currently looking for a remote backend, full-stack or AI-engineering role with a team that takes correctness seriously. The projects above are where I keep that thinking in the open.
